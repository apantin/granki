# Документация Granki

Как установить, обновить и начать — в [README репозитория](../README.md). Точные форматы файлов — в [formats.md](../skills/granki-tools/references/formats.md). Это основной документ по форматам, остальные на него ссылаются.

## Для пользователя: `user/`

Как вести серию с Granki.

| Документ | О чём |
|---|---|
| [tutorial.md](user/tutorial.md) | Туториал: одна статья вымышленной серии от плана до публикации и новой версии, с настоящим выводом скриптов |
| [process.md](user/process.md) | Шесть уровней работы, цикл плана и раздела, ревью, журнал, статусы статей, правила для опубликованных статей и работы с автором |
| [roles.md](user/roles.md) | Роли агентов и составы комнат для ролевых обсуждений |
| [example/](example/README.md) | Примеры: HTML-версии статей и серий пилота, вымышленная серия «Хлеб на закваске» для туториала и слепой тест «где нейросеть» |
| [conflicts.md](user/conflicts.md) | Конфликты с другими наборами скиллов и как отключить их в проекте: Claude Code, Codex, Gemini CLI, Copilot, OpenCode, Cursor, Windsurf |
| [CHANGELOG.md](../CHANGELOG.md) | Изменения по версиям и что сделать при обновлении |
