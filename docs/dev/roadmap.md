# Дальнейшие шаги

## Пилот на реальной серии

1. **Пилот на одной статье.** Автор вычитывает восстановленный план, два-три раздела проходят полный цикл, затем ревью статьи. Результат — оценка удобства автором.
2. **Ревью серии.** Итоговая сверка всей первой серии: отчёт ревью серии и решения по статьям с учётом статусов публикации.
3. **Подрезка.** Шаги, комнаты и линзы, которые не изменили результат, убираются. Скилл держится, только пока он лучше голой модели.

## После пилота на вымышленных сериях

Итоги — в [pilot.md](pilot.md).

| Что | Почему |
|---|---|
| Голос против голой модели | Granki честнее во всех сравнениях, но уступает голой модели по голосу. Проход голоса сокращает разрыв, письмо целиком — нет. Следующий кандидат — авторские подсчёты через `expr:` в плане статьи, а не только в тексте |
| Число находок на раздел | 10–25 находок на раздел и 14–34 на статью; автор жалуется на длинные списки мелочей и после группировки. Нужен порог: что линза не заводит вовсе |
| Повторные прогоны в оценке | Шум и генерации, и судей — около ±0,5; выводы меньшего размера требуют 3–5 повторов |
| Симулятор автора с памятью | Симулятор не помнит прошлых этапов и дважды не узнал свою фразу |
| Модель агента | Sonnet честнее и полезнее по оценке судей, Opus живее; Sonnet дешевле за ход, но ходов и находок у него больше |

## Не сделано в 0.1.0

| Что | Зачем |
|---|---|
| Поячеечная сверка таблиц рукописи с CSV | Сейчас скрипты проверяют только числа прозы. Нужно декларативное описание таблиц в плане статьи |
| Слова вместо чисел («в три раза») и однозначные числа | Скрипт их не видит, сейчас их ловят линзы ревью |
| Сборка PDF, HTML одного раздела или плана | Автору удобнее читать план и раздел в браузере |
| Интерактивные комнаты в живой сессии с автором | Планёрки и разбор раздела проверены только разбором составов, фокус-группа — в режиме субагентов |
| Установка по URL GitHub | Заработает после первого push и тега `v0.1.0`, см. [release.md](release.md#первый-выпуск-010) |
| Версия формата в файлах серии и миграции | Сейчас серия не помнит, какой версией Granki сделана. При несовместимом изменении формата нужна проверка версии и скрипт миграции |
