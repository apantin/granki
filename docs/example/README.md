# Примеры

Статьи и серии, которые получились в пилоте Granki ([pilot.md](../dev/pilot.md)), со всеми рабочими материалами, и вымышленная серия для туториала. В пилоте авторов играли агенты с досье, данные вымышленные.

Начните с [index.html](index.html): оттуда ссылки на готовые статьи и на [changes.html](changes.html) — что менялось между версиями. Страницы открываются в браузере без сети.

| Папка | Что |
|---|---|
| `winter-bike/` | Пилот A, серия «Зимой на велосипеде» из двух статей, на Granki до правок пилота |
| `winter-bike-studs-final/` | «Девять тысяч за шипы» заново, со всеми правками пилота и проходом голоса (E5 в `pilot.md`). Статья 01 в этой папке не писалась |
| `ci-cache/` | Пилот B, «Кэш зависимостей в CI: что он нам дал» |
| `dacha-solar/` | Пилот C, контрольная тема: «Первое лето с солнечной станцией на даче» |
| `bread/` | Вымышленная серия «Хлеб на закваске» для [туториала](../user/tutorial.md), [README](bread/README.md) |
| `blind-test/` | Слепой тест «где нейросеть» для людей: три темы пилота, по три текста без подписей, ключ отдельно, [README](blind-test/README.md) |

## Что лежит в папке пилота

Рабочая папка автора, как её оставил пилот, без ядра BMad и скиллов:

| Путь | Что |
|---|---|
| `html/` | Готовые страницы: `index.html` серии и по файлу на статью; `manifest.json` — отчёт сборки |
| `.agents/canon.md` | Канон проекта: правила текста для всех серий автора (в пилоте B не создавался) |
| `materials/` | Старые посты автора — образец голоса |
| `<серия>/series-plan.md` | План серии: читатель, жанр, статьи и их статусы |
| `<серия>/author-notes.md`, `journal.md`, `canon.md` | Заметки автора, журнал серии, правила серии (если есть) |
| `<серия>/shared/` | Общие данные и источники серии |
| `<серия>/reviews/` | Ревью плана серии и серии целиком |
| `<серия>/<статья>/plan.md` | План статьи: разделы, тезисы, опоры, оговорки |
| `<статья>/data/` | Данные и таблица утверждений `claims.csv` |
| `<статья>/sections/` | Разделы статьи — исходник HTML |
| `<статья>/journal.md` | Журнал статьи: находки ревью, решения автора, действия |
| `<статья>/reviews/` | Отчёты проверок агентами: план, каждый раздел, статья |

## Как пересобрать

Страницы статей — `skills/granki-tools/scripts/build_html.py`: `--series <series-plan.md> --output <папка>/html` для серии, `--plan <plan.md>` для отдельной статьи. `changes.html` собирает скрипт стенда пилота из текстов, которые сравнивали судьи, и снимков этапов в git рабочих папок; в репозиторий он не входит.
