# Примеры

HTML-версии статей и серий, которые получились в пилоте Granki ([pilot.md](../dev/pilot.md)), и исходники примера для туториала. В пилоте авторов играли агенты с досье, данные вымышленные. Откройте [index.html](index.html) в браузере: страницы не загружают ничего из сети.

| Папка | Что |
|---|---|
| `winter-bike/` | Пилот A, серия «Зимой на велосипеде» из двух статей, на Granki до правок пилота |
| `winter-bike-studs-final/` | «Девять тысяч за шипы» заново, со всеми правками пилота и проходом голоса (E5 в `pilot.md`) |
| `ci-cache/` | Пилот B, «Кэш зависимостей в CI: что он нам дал» |
| `bread/` | Исходники вымышленной серии «Хлеб на закваске» для [туториала](../user/tutorial.md): канон, планы, журналы, разделы |
| `dacha-solar/` | Пилот C, контрольная тема: «Первое лето с солнечной станцией на даче» |

Страницы собраны `skills/granki-tools/scripts/build_html.py` (`--series` для серий, `--plan` для отдельной статьи); `manifest.json` в каждой папке — его отчёт о проверке страниц. Исходники статей остались в рабочих папках пилота и в репозиторий не входят.
