# Слепой тест: где нейросеть

Тексты для людей: по каждой теме три статьи без подписей — голая модель и две версии Granki. Читатель решает, где писал человек, а где нейросеть, и какой текст опубликовал бы. Ключ к каждой волне лежит отдельно; открывайте его после ответов.

Волны независимы: во второй все тексты новые, её можно проходить и тем, кто проходил первую.

| Волна | Собрана | Что в ней |
|---|---|---|
| [Волна 1](wave-1/README.md) | 2026-11-23 | Ветка до отзыва читателей: правила раундов 1–17 и вступление плана. |
| [Волна 2](wave-2/README.md) | 2026-11-23 | После отзыва читателей на первую волну: тире, ровные поправки, зачин блогера, слова автора проходят проверку. Все тексты новые, в том числе голая модель и старый Granki. |

Набор собирает скрипт стенда стиля; темы и авторы вымышленные, это серии пилота ([примеры](../README.md)).
