# Слепой тест, волна 2

После отзыва читателей на первую волну: тире, ровные поправки, зачин блогера, слова автора проходят проверку. Все тексты новые, в том числе голая модель и старый Granki.

Девять статей на три темы. Каждую тему написали три раза: голая модель и две версии Granki. Какая где — в [ключе](KEY.md); откройте его только после ответов.

Темы и авторы вымышленные, это серии пилота ([примеры](../../README.md)). Старые посты автора — образец его голоса, как его видели судьи-модели. Числа в статьях из одних и тех же данных.

## Как проходить

1. Возьмите тему, при желании сначала пролистайте посты автора.
2. Прочитайте три текста темы в любом порядке.
3. Для каждого текста ответьте в [форме](ANSWERS.md):
   1. Написал человек или нейросеть? Уверенность от 1 до 5.
   2. Одна-две цитаты, по которым вы это поняли.
   3. Если бы это был блог знакомого, дочитали бы до конца?
4. По теме в целом: какой из трёх текстов вы бы опубликовали.

Порядок тем и букв случайный. Тексты не правились руками: какими их оставил прогон, такими и лежат.
