# Кандидаты в тезисы

Медиана везде — по всем статусам сборок (ok, fail, flaky), с числом сборок в скобках.

1. **На тех же раннерах кэш сократил медиану полного пайплайна на 43%, примерно в 1,8 раза.** 888 с (145 сборок) → 502 с (75 сборок). Опоры: [R-base-median], [R-base-n], [R-cacheold-median], [R-cacheold-n], [R-cache-effect], [R-cache-ratio]. Сила: средняя. Раннеры одни (old-4cpu), но периоды разной длины (4 недели против 2) и разного времени; другие изменения около 3 ноября не исключены.
2. **По успешным сборкам результат почти тот же: −45%.** 881,5 с (130) → 486 с (66). Опоры: [R-ok-base-median], [R-ok-base-n], [R-ok-cacheold-median], [R-ok-cacheold-n], [R-ok-effect]. Сила: средняя, та же, что у тезиса 1; показывает, что упавшие и флаки-сборки вывод не меняют.
3. **Дальнейшее ускорение пришло с новыми раннерами: 502 с (75) → 338 с (69), ещё −33%.** Опоры: [R-cacheold-median], [R-new-median], [R-new-n], [R-runner-step]. Сила: слабая как оценка вклада раннеров — на new-8cpu нет сборок без кэша (S-C4), это кэш и раннеры вместе. Годится только чтобы отделить эффект раннеров от эффекта кэша.
4. **Промахи — 12 из 144 сборок с кэшем, около 8%; автор ожидала около 3%.** Опоры: [R-miss-n], [R-cache-n], [R-miss-share], [R-miss-expected]. Сила: счёт точный; причины промахов в выгрузке не видны.
5. **На старых раннерах сборка с промахом не быстрее, чем без кэша: медиана 1001 с (7) против 888 с (145).** Опоры: [R-oldmiss-median], [R-oldmiss-n], [R-base-median], [R-base-n]; для сравнения попадания — [R-oldhit-median], [R-oldhit-n]. Сила: слабая, 7 сборок.
6. **На новых раннерах разрыв попадание/промах, похоже, меньше: 335 с (64) против 552 с (5).** Опоры: [R-newhit-median], [R-newhit-n], [R-newmiss-median], [R-newmiss-n]. Сила: очень слабая, 5 промахов. Кандидат плана серии: в статью разве что одной осторожной фразой.
7. **Флаки-сборок по периодам: 8, 2, 1.** Опоры: [R-flaky-base], [R-flaky-cacheold], [R-flaky-new]. Сила: только счёт; причин снижения не знаем, выводов не делаем.
