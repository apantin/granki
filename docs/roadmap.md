# Дальнейшие шаги

## Пилот на реальной серии

1. **Пилот на одной статье.** Автор вычитывает восстановленный план, два-три раздела проходят полный цикл, затем ревью статьи. Результат — оценка удобства автором.
2. **Ревью серии.** Итоговая сверка всей первой серии: отчёт ревью серии и решения по статьям с учётом статусов публикации.
3. **Подрезка.** Шаги, комнаты и линзы, которые не изменили результат, убираются. Скилл держится, только пока он лучше голой модели.
