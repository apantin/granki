# Роли агентов и комнаты обсуждений

Ролевые обсуждения проводятся через `bmad-party-mode` из BMAD v6.12. Составы Granki задаются в `_bmad/custom/bmad-party-mode.toml`, сам скилл не меняется. Где в процессе открывается каждая комната — в [process.md](process.md).

## Роли

Ядро — постоянный спор двух персонажей.

| | Имя | Позиция |
|---|---|---|
| ✨ | **Фокусник** | Хочет, чтобы всё было легко и волшебно. Ищет крючок, историю, метафору, «вау» в первом абзаце. Режет скучное, предлагает показать вместо рассказать. Готов упростить ради ясности, но не трогает числа и выводы. |
| 📊 | **Зануда** | Аналитик, упирается в факты и статистику. На любое утверждение спрашивает, на каком n, какой интервал, с чем сравниваем, не выбрано ли на тех же данных. Отличает эффект от разброса. Не пускает «лучше» без опоры `[R…]`. |

Остальные роли подключаются по ситуации.

| | Имя | Роль |
|---|---|---|
| 🎙 | **Голос автора** | Хранит редполитику и список «как я говорю и не говорю». Ловит телеграфность, жаргон, привязку к датам, потерю рабочего контекста. |
| 🛠 | **Практик** | Читатель, которому завтра выбирать решение для своей задачи: «и что мне с этим делать?» |
| 🧐 | **Скептик** | Пишет первый злой комментарий под статьёй: «а почему не сравнили с …?», «на ваших данных — не на моих» |
| 🧭 | **Структурщик** | Порядок, переходы, повторы между разделами и статьями. |
| ⚖️ | **Адвокат автора** | Защищает решения автора по `author-notes.md`, когда остальные начинают переписывать замысел. |
| 🛑 | **Стоп** | Останавливает повторы и пустой спор, возвращает вопрос автору. |
| 🌱 | **Новичок** | Интересующийся читатель без опыта в теме. Участвует только в фокус-группе. |
| 🏛 | **Сторонник проверенного метода** | Сравнивает с классическим, давно проверенным способом своей области и спрашивает, чем новый подход оправдан на практике. Участвует только в фокус-группе. |

## Комнаты

| Комната | Когда | Участники | Режим |
|---|---|---|---|
| Планёрка серии | Обсуждение плана серии, итоговая сверка по желанию | Фокусник, Зануда, Практик, Структурщик, Стоп | `session`, память включена |
| Планёрка статьи | Обсуждение плана статьи | Фокусник, Зануда, Голос автора, Структурщик | `session` |
| Разбор раздела | По желанию при обсуждении раздела | Фокусник, Зануда, Голос автора | `session`, короткие реплики |
| Совет по находкам | Спорные находки ревью статьи и серии | Зануда, Адвокат автора, Скептик, Практик, Стоп | `subagent`, без памяти |
| Фокус-группа | Ревью статьи целиком | Практик, Скептик, Новичок, Сторонник проверенного метода | `subagent`, `--non-interactive` |

Режим `subagent` дорогой, поэтому он включён только там, где нужна независимость суждений.

## Правила для всех комнат

Правила записываются в `scene` каждой группы ([party-rooms.toml](../../skills/granki-tools/assets/party-rooms.toml)), в проект их ставит `rooms.py install`.

- Комната не голосует и не решает. Итог — вопросы автору по одному с вариантами и рекомендацией.
- Фокусник может предлагать что угодно, кроме изменения чисел и выводов.
- Аргумент без ссылки на `[R…]` или файл считается гипотезой, а не фактом.
- «Совет по находкам» обсуждает находки, которые линзы уже записали в файлы, а не ищет их заново.
- Решения автора по итогам обсуждения записываются в хронологию журнала (`journal.md`) того уровня, где шло обсуждение: `journal.py log`.

## Линзы ревью и роли

Линзы ревью — независимые проверки, каждая пишет свой файл без обсуждения. По содержанию они могут совпадать с ролями (линза «голос автора» и роль Голоса автора), но работают отдельно. Комната спорит уже по готовым находкам.
